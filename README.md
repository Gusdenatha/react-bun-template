# React Bun Template

Starter template frontend berbasis React, TypeScript, Bun, dan Vite yang dirancang agar mudah digunakan kembali untuk berbagai proyek.

## Technology

- React
- TypeScript
- Bun
- Vite
- React Router
- TanStack Query

## Instalasi

```bash
bun install
```

## Development Server

```bash
bun run dev
```

## Build Production

```bash
bun run build
```
